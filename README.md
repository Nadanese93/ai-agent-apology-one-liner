## Contest

Entry for [The AI Agent Apology One-Liner](https://make.fun/bounty/u-kiencx-the-ai-agent-apology-one-liner-cfedd447) on make.fun — a single short line (1–159 characters) apologizing for an AI agent mishap.

## Run

```sh
python3 main.py
```

This writes the entry to the MAKEFUN_OUTPUT_DIR/entry.txt path (defaults to ./output/entry.txt), validating the contest gate first: UTF-8, 1–159 characters, not only whitespace, one line.
